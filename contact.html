Ticket

Install,
four steps.

  1. Step 1

    $ Clone the repository and open the plugin folder.

  2. Step 2

    $ Register hermes-solverforge-routing with your Hermes Agent plugin manifest.

  3. Step 3

    $ Point the plugin at your SolverForge endpoint in its config file.

  4. Step 4

    $ Restart the agent and send a routing request to confirm the docked map renders.

Every step runs locally; no accounts, no payments, no outside services.

Command reference

Every command,
spelled out.

  • /route

    send a request to SolverForge and get an optimized route back.

  • /map

    open or close the docked chat-plus-map view.

  • /solver status

    check whether the SolverForge endpoint is reachable.

  • /solver config

    show the active plugin configuration.

  • /solver reset

    clear the current route and start a fresh request.

  • /help solverforge

    list every command the plugin adds.
