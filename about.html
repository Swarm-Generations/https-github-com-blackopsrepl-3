hermes-solverforge-routing

The flow, step by step.

  1. 01

    Request

    You write the routing problem in plain language in the Hermes Agent chat.

  2. 02

    Dispatch

    The plugin packages the request and sends it to SolverForge.

  3. 03

    Solve

    SolverForge runs its route optimization and returns the solution.

  4. 04

    Return

    The result lands back in the chat as a readable answer.

  5. 05

    Draw

    The same result renders on the map docked to the right of the conversation.
